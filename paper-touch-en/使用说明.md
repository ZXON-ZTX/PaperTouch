# PaperTouch

调用：`$paper-touch-en`。这是独立的英文版本，核心是白名单式最小改动：没有明确命中规则的文字、原有框架和科学内容保持原样。

适用于英文摘要、正文、方法、讨论、综述和审稿回复的成稿清理。它不负责从零写论文，也不默认承担全面语法校对、重构论证、核验研究结论或降低某个检测百分比。

## 两种模式

默认仍为原有白名单模式，只处理E1–E6。新增的“专家润色”必须明确提出才启用，针对计算机与网络空间安全已有英文稿，在授权范围内调整语法、表达与句内/句间衔接；不自动重组段落，不改变科学内容或结论强度。风格指南来自公开论文语料分析及选定章节研读，不是模型参数训练，也不代表已证明作者身份或检测效果。

```text
使用 $paper-touch-en 的专家润色模式，修改下面网络安全论文段落。
改善英文表达和局部衔接，保留攻击者能力、实验条件、数字、引用、研究状态与结论强度。
只输出修改后的段落。
[粘贴英文原稿]
```

专家模式也支持“仅审核、不修改”。若未指定专家模式，继续使用原白名单范围。完整指南见references/expert-editing.md，学习依据和边界见references/style-evidence.md及references/style-sources.json。scripts/apply_edits.py仅用于E1–E6，不用于套用专家润色修改。

两种模式共同遵循克制编辑原则：完整交付指定任务，只为具体问题增加工作，保留有效保护，复用仍适用的核对结果，验收充分后停止。流程说明和未请求的预防性文字不写入论文；原有科学局限、不确定性及必要披露继续保留。这些是行为指导，不提供Guard/Hook强制拦截。

## 六类允许的修改

1. 空泛且无必要的强调提示语，如`It is worth noting that`。
2. 两组冗长功能短语，如`in order to`→`to`，但服从作者风格和语义。
3. 明确可等价动词化的结构，如`conducted an evaluation of`→`evaluated`。
4. 同一位置重复叠加的添加连接词，不删必要转折或因果关系。
5. 同一数值前重复的近似词，如`approximately about`→`approximately`，保留近似性。
6. 功能已经明确、没有独立技术含义的装饰性职业拟人，不改模型中的assistant/critic等真实角色。

被动语态、长句、三项并列、真实对比、学术限定、专业术语及`novel/significant/prove`等单词本身都不是改写理由。编号标题、表格、公式、引用、代码、引语、阴性结果和必要披露保留。作者已提供的风格指南优先于一般风格触发规则。

## 用法

```text
使用 $paper-touch-en 清理下面英文论文段落。
只按白名单修改，保留所有未命中文字、数据、引用和段落结构，只输出改后全文。
[粘贴英文原稿]
```

```text
使用 $paper-touch-en，仅审核、不改写。
列出命中的E1–E6、原文位置及最小修改建议；未命中项目不要扩展处理。
```

如有作者风格样本，可随任务提供。不要仅为制造节奏或追求某检测分数反复重写；范围外的表达或科学问题需要另行提出。

## 文件工具与安装

已安装时在下一轮直接调用；若未发现可重启Codex。手动迁移可将整个`paper-touch-en`目录放入目标环境的技能目录，目录内保留SKILL.md及references/scripts等子目录。

UTF-8文本、Markdown和LaTeX可以使用`scripts/apply_edits.py`应用已审阅的局部补丁；工具验证未改区域、字面锚点、受保护结构、数字和基本否定/模态词，拒绝覆盖既有输出。具体格式见`references/patch-format.md`。它不能判断科学语义是否等价，也不是完整的Markdown/LaTeX解析器；Word/PDF需要相应文档工具，不直接交给该脚本。

原项目的实测主体是中文语料，本版没有将中文比例冒充英文实测结论。源码归属与MIT许可保留，详见LICENSE和references/source-notes.md。

## 保护检查与测试

六条编辑规则和处理范围保持不变。补丁工具继续整行保护已识别的列表、表格、标题和块引用，不开放内部改写。新增保护检查覆盖常见数值单位、cannot及常见否定缩写、部分模态/研究状态词和单行英文单引号引文；同时检查完整原文与改后文本，减少局部截词绕过保护的情况。

这些检查不能代替语义判断，也不能识别全部单位、否定表达或引文结构。未识别的专业单位、跨行/嵌套或边界有歧义的引文，仍需通过protected_terms/protected_ranges保护并人工复核。具体范围见references/patch-format.md。普通author's/can't中的撇号本身不视为引文起点。

技能目录内运行`python -B -m unittest discover -s tests -v`可执行随包测试，无需安装第三方测试依赖。测试通过表示所列机械保护案例通过，不表示论文科学内容或检测分数通过。
